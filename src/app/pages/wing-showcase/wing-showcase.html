Wing

A CSS framework for minimalists, rebuilt on Tailwind v4.

See it work Read the guide

Drop it in

One class on a wrapper styles every element inside it. Toggle it to see the same markup with and without Wing.

Decisions

Scoped, not global

Original Wing restyles every bare element. Here that is opt-in through .wing, so it never leaks into the rest of an app.

Tokens, not overrides

Colors, type and shadow are Tailwind theme variables. Remap --color-wing-blue once and everything follows.

Layered, so utilities win

Wing lives in the base and components layers. Any Tailwind class on the same element overrides it.
